# 預建攔截庫（產品主路徑）

## 用戶承諾

付 HK$1／月 → 取得 Call Guard **已預先查好**、針對「喺香港收到」嘅：

- 騷擾電話  
- 疑似騙案電話  
- 推銷電話  
- 財務借貸推介  

呢啲號碼寫入系統欄截後，**唔應該再响到付費會員**。

唔係：等人中招 → 自己 block → 下一個人先受惠。  
而係：庫先存在 → 付費即攔。

## 同競品差異（講法）

| | 常見體驗 | Call Guard |
|---|---|---|
| Whoscall | 多人用成「响咗先睇」 | 付費即用預建攔 |
| Call Defender | 亦有預載庫（HKJunkCall 等） | 極簡＋$1＋只攔四類＋只顯示被攔紀錄 |
| 舉報 | 有時當主功能 | **只補漏** |

## 資料點預先查（營運 checklist）

1. 每日／每週匯入公開滋擾／騙案相關號碼（合法公開來源）  
2. 分類入 `harassment` / `scam` / `telemarketing` / `loan`，`region=HK`  
3. 人工抽樣核對，降 false positive  
4. 付費會員 App 啟動／下拉「同步名單」拉最新庫  
5. 會員舉報 → 審核後入庫（輔助，唔替代預建）

禁止：整庫爬取 Whoscall 等私有數據庫。
